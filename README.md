# AI-Unity-EggCollector

> 一款基于 Unity 引擎的动物角色扮演儿童益智游戏，采用 Gemini + DeepSeek + 豆包的 AI 辅助开发流程完成。


## 📖 项目简介

本项目是浙江科技大学 2025届工业设设计作品，题目为《AI 模型结合 Unity 进行游戏开发》。

玩家操控一只小动物角色，在限定时间内收集场景中所有的蛋。场景中存在敌人，靠近时会追逐并攻击玩家。全部收集即为胜利，倒计时结束或角色死亡则游戏失败。

开发过程中，使用 **Gemini** 进行顶层设计与逻辑梳理，**DeepSeek** 辅助代码生成，**豆包** 进行代码复核，最终在 **Unity** 引擎中完成全部功能的实现。



## 🎮 游戏玩法

- 在倒计时结束前，收集场景中全部的金蛋
- 靠近蛋时会出现进度条，进度条满即可完成收集
- 屏幕右下角显示当前收集进度
- 场景中分布有敌人，靠近时会主动追逐并攻击你
- 全部收集 → **胜利**；时间耗尽或死亡 → **失败**


## 🕹️ 操作说明

| 按键 | 功能 |
|------|------|
| `W` `A` `S` `D` | 角色移动 |
| `左 Shift` | 加速奔跑 |
| `鼠标左键` | 攻击 |
| `鼠标滑动` | 控制视角 |
| `鼠标滚轮` | 调整镜头距离 |
| `Esc` | 退出游戏 |


## 🛠️ 技术栈

| 工具 | 用途 |
|------|------|
| **Unity** | 游戏引擎，场景搭建与最终发布 |
| **Gemini** | 项目顶层设计、逻辑梳理、开发流程规划 |
| **DeepSeek** | 游戏逻辑代码生成与技术实现 |
| **豆包** | 代码复核、细节优化、问题排查 |

**开发流程**：

Gemini 统筹规划 → DeepSeek 生成代码 → 豆包复核优化 → Unity 落地开发



## 📁 项目结构


Assets/
├── Scripts/           # 游戏脚本
├── Player.cs      # 玩家控制（移动、攻击、受击）
├── Enemy.cs       # 敌人 AI（寻路、追击、攻击）
├── Egg.cs         # 收集物逻辑（触发检测、进度条）
├── GameManager.cs # 游戏流程管理（倒计时、胜负判定）
├── CameraController.cs  # 相机跟随与视角控制
└── StartManager.cs      # 开始界面管理
├── Scenes/            # 游戏场景
├── Start.unity    # 开始界面场景
└── GameScene.unity    # 游戏主场景
├── Animations/        # 角色与敌人动画
├── Prefabs/           # 预制体（角色、敌人、蛋等）
├── UI/                # 界面资源
├── Audio/             # 音频资源
└── Materials/         # 材质与天空盒




## 🚀 快速开始

### 环境要求
- Unity 2022.3 或更高版本
- Windows / macOS

### 运行步骤
1. 克隆本仓库
   bash
   git clone (https://github.com/Ding0418/AI-Unity-EggCollector.git)

1. 使用 Unity Hub 打开项目文件夹
2. 在 Project 窗口中找到 Assets/Scenes/Start.unity，双击打开
3. 点击 Unity 编辑器顶部的 ▶️ Play 按钮即可运行

· 多工具组合（规划型 + 编码型 + 复核型 AI）能否形成高效开发流程？
· AI 生成代码在 Unity 环境中的可靠性与适配性如何？
